# NOVA AI

NOVA AI is a serverless AI-powered web application built using AWS cloud services and modern web technologies. The platform enables users to interact with an AI assistant through a secure and scalable cloud-native architecture.

## Features

* AI-powered conversational assistant
* Secure user authentication and authorization
* Persistent chat history storage
* Serverless backend architecture
* REST API integration
* Cloud-native deployment

## Tech Stack

### Frontend

* React.js
* HTML
* CSS
* JavaScript

### Backend & Cloud Services

* AWS Amplify
* AWS Lambda
* Amazon API Gateway
* Amazon Cognito
* Amazon DynamoDB
* Amazon Bedrock (Claude Haiku)

## Architecture

1. Users authenticate through Amazon Cognito.
2. Requests are routed through Amazon API Gateway.
3. AWS Lambda processes user queries.
4. Amazon Bedrock generates AI responses.
5. Chat conversations are stored in DynamoDB.
6. AWS Amplify hosts and deploys the application.
